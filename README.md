# MAPCO2-QC-Public
Mooring group MAPCO2 QC software, specific to xCO2

# Getting started

Hakai fork, set up for uv and Positron on macOS. See the [setup guide](docs/GUIDE.md).

<details>
<summary>Legacy conda installation (upstream)</summary>

The original instructions used Anaconda: create an `xco2qc` conda environment from
`xco2qc/xco2qc/core/data/environment.yml`, install `pyco2sys` with pip, then run
`jupyter notebook` from `xco2qc/` and open `ocean_CO2_QC.ipynb`.

</details>
